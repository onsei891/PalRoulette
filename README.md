# PalRoulette

Fan-made Palworld randomizer for generating random Pal teams and challenge rosters.

## Features

- Random Pal selection with animated roulette picks.
- Filters for element, role, obtainable Pals, and duplicate picks.
- Adjustable roster size from 1 to 50.
- Custom SVG icons for elements and work suitabilities.
- Static Astro build for easy deployment to Cloudflare Pages, Vercel, Netlify, or GitHub Pages.

## Development

```sh
npm install
npm run dev
```

Build the static site:

```sh
npm run build
```

## Data

Pal data is based on [`beliarance/palworld-kb`](https://github.com/beliarance/palworld-kb/blob/main/data/index.json).
